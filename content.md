In Python the `print`{.python} function is used to display output. This can be useful for reporting results to the user or debugging code. To use it, write the word `print`{.python} followed by parentheses containing the values you wish to print, such as in the example below:

```py-cell
print(42)
```

You can also provide multiple values to the `print`{.python} function by separating them with commas. The values will be printed with a space in between them by default:

```py-cell
print(999, 42)
```

By default, the `print`{.python} function adds a newline character at the end of the output, which means that subsequent print statements will appear on a new line:

```py-cell
print(10)
print(9)
```
